# Szakdolgozat – Online könyvesbolt React alapon

Ez a projekt egy online könyváruház, amely külön frontend és backend részből áll.

Projekt indítása:
A projekt indításához a projekt gyökérkönyvtárát kell megnyitni PowerShell-ben. A gyökérkönyvtárból be kell lépni a backend mappába a cd backend parancs segítségével. Első indításkor le kell futtatni az npm install parancsot, majd az npm run dev paranccsal elindul a szerver. Ezután egy új terminálablakot kell nyitni, és a projekt gyökérkönyvtárából az npm run dev paranccsal elindítható a frontend alkalmazás.
